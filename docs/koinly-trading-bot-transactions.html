Koinly and trading bots: thousands of fills, one bill per fill

Updated October 2026. Not tax advice.

A grid bot running for a few months can easily produce tens of thousands of fills. Koinly counts each one as a transaction and its plans stop at 10,000 (roughly $10 per extra 1,000 after that). Users on Koinly's forum and feedback board describe it plainly: 40,000 KuCoin bot records in four months (thread), or "73000 micro transactions from my $100 experiments" and a $900 upgrade (feature request, open since 2022).

What Koinly can and can't do in the app

  • Bulk aggregate works for deposits only (hourly or daily, one wallet and tag at a time). Bot fills are trades, so it doesn't apply. (Koinly article)
  • Manual merge joins up to 9 same-day transactions at a time. Not realistic for thousands.
  • Koinly aggregates some exchanges' own CSVs on import (it has done this for Binance), but not every export or bot product.

Merge the fills before you import

  1. Export the bot's filled orders or trade history as CSV from the exchange.
  2. Open TxSqueeze and drop the file in. For an exchange file, the page guesses column roles: pair/symbol, side and fee currency must match; amounts, volumes and fees are summed; prices are averaged; IDs and times keep the last value. Check the table and adjust if needed.
  3. Choose per day (default), week or month. Buys and sells stay separate because side is a keep-apart column.
  4. Download. The file keeps the exchange's header and column order, so import it into Koinly the same way as the original (remove the API connection or the original file for that wallet first).

A synthetic test with a 3,600-fill ETH-USDT grid bot over 90 days gave 180 rows per day-and-side, which on its own is the difference between Koinly's Pro plan (over 3,000) and Hodler (up to 1,000).

Is daily merging accurate enough?

Summing a day's buys and a day's sells of the same pair keeps the day's total cost and proceeds; the gain is then computed on daily lots instead of per fill. Koinly support recommends merging per day/week/month for the same reason. Rules differ by country; ask your accountant if your bot's volume is material.
