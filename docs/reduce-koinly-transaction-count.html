How to reduce your Koinly transaction count

Updated October 2026. Not tax advice.

"You have exceeded the total number of transactions allowed on your account. Please reduce your transaction count or purchase a tax plan." If you have seen that banner, the cause is usually not trading. It is small, repetitive rows:

  • Daily staking and Earn rewards. Binance Simple Earn, Launchpool and staking pay one row per coin per day (or more). 10 coins for a year is 3,650 transactions.
  • Trading bots. Grid and DCA bots on KuCoin, Pionex or Binance split every order into many fills. One forum user found 73,000 micro-transactions from small bot experiments.
  • Fees and dust booked as separate rows.

Koinly bills by transaction count (about 100 / 1,000 / 3,000 / 10,000 for its four plans, then roughly $10 per extra 1,000), so these rows decide which plan you need.

What Koinly support recommends

On Koinly's own forum, support staff give the same two options every time (1, 2):

  1. Merge in the app: select up to 9 same-day transactions with the same label and merge them. Repeat. Fine for a handful of days; painful for a year.
  2. Sum them in the CSV: "tally up all the rewards received on a certain day/week/month and add a single deposit for the whole amount", then import via CSV instead of API so you control the rows.

Doing option 2 without a spreadsheet marathon

  1. Download the CSV from the exchange (for Binance, the "Generate all statements" export under Transaction History).
  2. Open TxSqueeze and drop the file in. Binance transaction history and Koinly universal CSV are detected automatically. For Binance it merges only reward-type operations (interest, staking rewards, distributions, airdrops, Launchpool, cashback, commissions) per day, account, operation and coin. Trades, deposits, withdrawals and Earn subscriptions/redemptions stay exactly as they were, because Koinly pairs them by timestamp.
  3. Pick day (closest to the original), week or month.
  4. Download the squeezed file. It has the same columns as the original.
  5. In Koinly, remove the API connection or the original file for that wallet first (otherwise you double count), then import the squeezed file the same way you would the original.

Everything runs in your browser; the file is not uploaded. Files up to 300 rows are free; larger files are a one-time $19.

Which period should I use?

Daily keeps each day's income at that day's price, which is closest to what the API import does. Weekly and monthly cut more rows but value the income at a single point in the period. If your rewards are a meaningful share of your income, ask your accountant; many are fine with daily.
